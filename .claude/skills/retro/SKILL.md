# /retro — セッション振り返り & 引き継ぎ

ジョニーの定義（2026-06-03）：**「引き継いで」と言われたら＝①プランを書く ②Linearに起票する ③現在地＋再開プロンプトをチャットに貼る まで**やる。本スキルはそれを定型化する。

## 実行手順

1. **振り返りを生成**（簡潔に）：
   - ①今日の成果（done）
   - ②学び（効いた手／伸ばす点／Claude活用のコツ）
   - ③資産化候補（スキル/仕組み/ナレッジ/voice-profile更新）
   - ④次アクション（優先順）

2. **セッションlog保存**：`content-engine/sessions/YYYY-MM-DD-<topic>.md` に上記を追記（無ければ作成）。

3. **Linear起票**（既存運用に準拠）：
   - team=`Jon_megane`、label=`handoff`、priority=内容に応じ（公開系はMedium）
   - title例：`[<topic>] <一行サマリ>（handoff）`
   - description：現在地／done／次タスクのチェックリスト／関連PR・ファイルのlinks／再開プロンプト
   - 関連があれば既存Epic（例：JON-53 絶滅職種図鑑）に relatedTo / parentId で接続
   - 既に同種issueがあれば新規作成でなく `save_issue` で更新

4. **現在地＋再開プロンプトをチャットに**（モバイルでも読める素のテキストで。mdリンクに依存しない）：
   - ブランチ / PR番号 / 触ったファイル / 公開先
   - 「次セッションはこれを貼れば再開」できる1段落のプロンプト

## 注意
- ジョニーはモバイル(RC)率が高い → **チャット直貼り**を徹底。ファイルリンクだけで済ませない。
- 既存の母艦システム（~/.claude の handoff / session-save / 素子）がある場合は競合させず、Linear起票で接続する。
- 公開・外部送信は係争中の安全弁（推定無罪・国籍で括らない・noteを先に）を継承。
