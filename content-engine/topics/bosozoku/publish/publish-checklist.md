# 公開前チェックリスト（bosozoku｜安全弁）

> 公開＝「貼るだけ」の直前に上から順に確認。1つでも✗が残るうちは公開しない。
> 全件、刑事係争中は容疑者表記・推定無罪・暴力や私的制裁を肯定しない・被害者を貶めない（backbone §9 厳守）。

## ① 福生事件（係争中）の取り扱い ⚠️最重要

- [ ] **容疑者表記に統一**（「男（容疑者・否認）」。「犯人」「加害者」と断定しない。"反応"を論じる文脈の「加害者に共感」は反応の記述としてOK、事実認定としては容疑者）
- [ ] **推定無罪を明示**（否認・係争中・57時間後逮捕の事実関係のみ。判決前の有罪断定なし）
- [ ] **暴力／私的制裁を肯定しない一文を本文に保持**（「本稿は暴力も私的制裁も一切肯定しない」）
- [ ] **被害少年を貶めない**（重傷を負った17歳が被害者。改造バイク騒音は"とされる"伝聞で、被害者落ち度論に傾けない）
- [ ] 分析対象は「事件への社会の"反応"＝症状」であって、犯行の是非判定でないことが読み取れる

- [ ] 「中国＝過去の日本」式の単線発展論／「移民＝犯罪」式の短絡を採っていない（後者は本論が批判するルサンチマンそのもの）
