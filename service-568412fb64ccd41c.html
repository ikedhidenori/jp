Offer 01 / Decision clarity

Reframe Sprint

課題の広がりを、次に検証する一つの問いへ。

1–2 WEEKS

Promise

会議を増やすのではなく、誰のどんな状態を変えるか、何を先に確かめるかを選べる状態にします。

START

顧客、課題、技術、案が広く、関係者の議論が発散。

ARRIVE

核心課題、優先利用場面、仮説、次の検証と判断者が明確。

Scope & outputs

Input
既存資料、関係者ヒアリング最大5名、現状の制約。
Deliverables
課題構造、一次情報と推測の分離、優先利用場面、検証判断シート。
Cadence
Kickoff、資料・ヒアリング、仮説レビュー、最終判断会。
Decision
進む／追加調査／止める、の次期ゲート。

受入条件：一次情報と推測が区別され、「次に誰の何をいつ確かめるか」を一枚でレビューできる。未合意点は論点として明記。

池田が担う
  • 課題再定義
  • 生活者視点の仮説
  • 判断材料の編集
依頼側が担う
  • 資料・関係者アクセス
  • 意思決定者の参加
  • 資料共有許可・社内調整
対象外
  • 大規模定量調査
  • 市場規模の保証
  • 最終事業決裁
実績との接続：LAC八ヶ岳の保養施設→Living Lab、オフグリッドの機器実証→生活実証。ケースを見る ↗
Offer 02 / Tangible hypothesis

Concept-to-Prototype

構想を、関係者が触れ、議論し、検証できる最初の形へ。

4–8 WEEKS

Promise

技術説明やアイデアを、利用場面・所作・世界観を持つ体験コンセプトと簡易プロトタイプへ変えます。

START

構想や要素技術はあるが、具体的な体験と評価方法がない。

ARRIVE

体験コンセプト、利用シナリオ、簡易試作、役割分担、実証計画。

Scope & outputs

Input
優先仮説、技術条件、利用者・現場へのアクセス、専門担当。
Deliverables
コンセプト、利用シナリオ、池田が作る紙・図・空間ラフ／体験モック、または専門担当が作る簡易試作のディレクション。
Cadence
観察、共創レビュー、試作、体験レビュー、次期判断。
Decision
作る／変える／止める、次の設計・開発投資。

受入条件：体験像、利用者に試すこと、次へ進む判断基準を一式でレビューでき、未確定の技術・運用条件が明記されている。

池田が担う
  • 体験コンセプト
  • 試作仕様・紙／図／空間ラフ
  • 共創ディレクション
依頼側が担う
  • 技術・事業責任者
  • 専門制作担当と試作費
  • 現場アクセス・知財判断
対象外
  • 量産設計
  • 詳細技術設計・施工
  • 完成品品質保証
実績との接続：FAB CARのコンセプト・スケッチ→実物、オフグリッド技術→生活実証環境。ケースを見る ↗
Offer 03 / Field validation

Living Lab / Field Pilot Design

場所・設備・体験・運営・募集・評価を、一つの実証へ。

4–10 WEEKS / DESIGN

Promise

視察やイベントで終わらせず、誰が何を体験し、何を学び、次の事業判断へ何を残すかを統合します。

START

地域資源や技術はあるが、複数担当が別々に動き、実証条件が定まらない。

ARRIVE

実証コンセプト、関係者・責任分界、場と運用、募集、評価、次期判断。

Scope & outputs

Input
現地、技術・運営条件、行政・地域・事業者、想定利用者。
Deliverables
実証Brief、体験導線、関係者マップ、運用・募集・評価設計、リスク・次期提案。
Cadence
現地観察、関係者整理、設計レビュー、実施可否ゲート。
Decision
実施／条件変更／延期／中止と、実施主体・予算化への入力。

受入条件：実証の目的、対象、役割、評価、中止条件を一枚で確認でき、未確定の許認可・技術・予算条件が明記されている。

池田が担う
  • 実証・体験コンセプト
  • 全体設計と役割接続
  • 利用者・広報の意味づけ
依頼側が担う
  • 許認可・地域調整
  • 予算・調達・最終決裁
  • 専門設計・安全管理
対象外
  • 行政手続き代行
  • 施工・設備技術設計
  • 集客・成果の保証
実績との接続：中城城跡の滞在実証、LAC八ヶ岳、オフグリッド・リビングラボ。ケースを見る ↗
03 / Commercial model

契約の組み方

価格ではなく、まず判断範囲と責任を固定。金額は市場検証中です。

Fixed-scope Sprint

Reframe Sprint向け。期間、ヒアリング数、成果物、レビュー回数を固定。

初回に切り出しやすい設計

Phased Project

Prototype／Pilot向け。Reframe→Concept→Pilotをゲートごとに契約。

不要な開発投資を止めやすい

Fractional Producer

方向が定まった後の伴走。池田の核心判断と、PM・専門担当を分離。

月次継続は別途適合確認

※ 期間は、必要資料、意思決定者、現場・利用者へのアクセスが着手時に揃う場合の標準目安です。守秘・知財・公開範囲は双方で契約前に合意します。本メニューは過去実績から設計した提供仮説であり、この名称・期間・成果物での販売実績や成約率は未検証です。最初の3件で、買い手の課題語、必要成果物、稼働、価格、継続条件を検証します。

04 / Start a conversation

最初の相談で伝えること

社名や機密を書かず、5点だけで適合を確認できます。

相談Brief

  1. いま止まっていること
  2. すでにある技術・構想・場所
  3. 次に決めたい判断
  4. 関係する専門家・決裁者
  5. 希望時期と公開できない条件
Xで相談する ↗Instagramで相談する ↗

初回30分の適合確認は費用を含め要相談。相談Briefの受領返信後に、日時・範囲・費用を確定します。公開投稿には社名・機密を書かないでください。

最初に確認する適合条件

  • 池田へ、課題設定または体験コンセプトの判断を任せられるか。
  • 意思決定者と専門担当がレビューへ参加できるか。
  • 現場・利用者・一次情報へアクセスできるか。
  • 既定仕様の制作代行だけを求めていないか。
  • 成果・責任・守秘・知財・中止条件を契約前に分けられるか。
