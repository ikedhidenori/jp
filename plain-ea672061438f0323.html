B. KDPの税務情報と振込口座 (約20分)

手元に用意するもの

  • マイナンバー (カードか通知カード)
  • 住所のローマ字表記 (例: 1-2-3 Jingumae, Shibuya-ku, Tokyo 150-0001)
  • 振込先の口座 (銀行名・支店名・支店コード3桁・口座種別・口座番号・名義のカナ)

1. 税務情報 (約10分)

  1. https://kdp.amazon.co.jp にサインイン (2段階認証)
  2. 右上の「アカウント」→「税に関する情報」→「税務プロファイルの作成」(または「税に関するインタビューを開始」)
  3. 画面の質問に答えます。迷いやすい所だけ:
    • 個人 / 法人 → 個人
    • 米国人ですか → いいえ
    • 氏名 → 本名(ローマ字)。ペンネームは不可
    • 居住国・国籍 → 日本
    • 住所 → 画面の形式に合わせて英語(ローマ字)で
    • 納税者番号(外国のTIN) → マイナンバー を入力 (日米租税条約が適用され、米国の源泉徴収が0%になります)
    • 租税条約の適用 → 画面の案内どおり「日本」で申請
  4. 最後に表示される W-8BEN の内容を確認し、電子署名(本名を入力)して送信
  5. 確認: 「アカウント」→「税に関する情報」で ステータス「完了」、源泉徴収率 0% と出ていればOK

2. 振込口座 (約5分)

  1. 「アカウント」→「支払いの受け取り方法」(または「銀行口座情報」)→「新しい支払い方法を追加」
  2. 銀行の所在国: 日本 → 口座名義(カナかローマ字、画面の指示どおり)・銀行名・支店コード・口座種別(普通)・口座番号を入力して保存
  3. マーケットプレイス (Amazon.co.jp) の支払い先にその口座が選ばれていることを確認

3. 著者情報 (確認だけ)

「アカウント」→「著者/出版者情報」: 本名・住所が入っていればOK (本の著者名「絶滅職種図鑑編纂室」とは別です)
