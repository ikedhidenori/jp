#1

えんやす って なに？

5 ステップで わかる ─ マクロ経済 のきほん

対象: 中学生〜マクロ経済はじめての人 / 所要: 約 12 分

「日本円が 世界で いちばん 弱い 通貨に なった」── そんなニュースを 見たこと、ある？

むずかしそうに 聞こえるけど、じつは 5 つの ことば さえ わかれば、ぜんぶ つながって 見えてくる。

このページでは、その 5 つを 順番に やっていくよ。
さいごに、ニュースの 言葉に もどって 「あ、こういうこと だったのか」と なれば 完成。

きょうの コース
1
STEP 1
おかね って なに？

おかね は、みんなが「これに ねうちが ある」と しんじてる 紙きれ。

お札 を じっと 見てみよう。素材は、ふつうの 紙より ちょっと いい紙。それだけ。紙そのものに ねうちは ない。

でも コンビニで お札 を 出すと、おにぎりが もらえる。なぜ？

お店の人 も、その奥の 工場 の人 も、農家の人 も、みんなが「この紙には ねうちが ある」と しんじてる から。
みんなで 信じてる ゲーム、それが「おかね」。

クラスで だれかが「この消しゴム 1 こ で ジュース 1 本と 交換できる ルール」と 言い出して、みんなが「いいね」と のったら、その瞬間に 消しゴム が 通貨に なる。
つぎの日に「やっぱ 消しゴム いらん」と なったら、ただの 消しゴム に もどる。
お札も、まったく 同じ しくみ。
こども え、じゃあ もし みんなが「日本円 やばそう」って 思いはじめたら…？
せんせい その瞬間 円の ねうちは 下がる。
これが 「為替が 動く」 の しょうたい だよ。
おかね の ねうち = その くに の 「信用 の 通知表」。
2
STEP 2
くに の しゃっきん って なに？

国 が「あとで 利息 つけて かえす よ」と 書いた 借用書 = 国債（こくさい）。

むずかしく 聞こえる 「国債」も、中身は ただの 借用書。

きみが ともだち に「10万円 かして、来年 10万5千円で かえす」と 紙に 書いて 渡す。
ともだちは その紙 を 持っておく。
来年に なったら、紙 と 引きかえに 10万5千円 もらう。
──これと まったく 同じ ことを、国 が やってる。借用書 の 名前 が「国債」って だけ。

じゃあ、誰 が 買ってる？
銀行、保険会社、年金、外国の 投資家、そして 日本銀行（にちぎん、BoJ）。
とくに 日銀 が ぜんたい の 半分以上 を 持ってる。これ、あとで 超 重要。

国債（借用書）の しくみ
くに の しゃっきん が 多すぎると、「ほんとに かえせるの？」 と うたがわれる。
うたがわれると、貸す人は 「もっと 利息 くれないと イヤ」 と 言う = 金利 が 上がる。
利息の 支払い が ふえる → さらに しゃっきん が ふえる → さらに うたがわれる → 詰む。
これが 「財政（ざいせい）危機」 の しょうたい。
3
STEP 3
きんり って なに？

金利 = お金 を かりる ときの レンタル料。家賃 と 同じ。

家を 借りたら 家賃を はらう。お金 を 借りたら 金利 を はらう。それだけ。

1 年間 で 100万円 借りる。
金利 が 3% なら、1 年後 に 103万円 返す。
その 3% が 「お金 の レンタル料」。

でも ここからが 大事。金利 には 「短期」と「長期」 の 2 種類 が ある。
これが Brooks の 話で いちばん 大事 な ところ。

短期 と 長期 は べつもの
こども え、なんで 通貨 に 効くのが 長期 の ほうなん？
せんせい 通貨 を 持つって「この くに に 長い時間 お金 を 置く」って こと。
1 ヶ月後 じゃなくて、10 年後・30 年後 が だいじょうぶ か どうか が 効くんだ。
通貨 の ねうち を きめる のは、短期 じゃなくて 長期 金利。
これ おぼえて おいて。Brooks の 話で フル活用 するよ。
4
STEP 4
にちぎん は なに を やってる？

日銀 は「銀行 の 銀行」。世の中 の お金 の 量 と 金利 を 調整する 役所。

3 つだけ おぼえれば OK。

  1. 短期 金利 を 上げ下げ できる (世の中の しゃっきん に ブレーキ or アクセル)
  2. 国債 を 買える / 売れる (世の中の お金 の 量 を 増やす or 減らす)
  3. 長期 国債 を たくさん 買うと、長期 金利 を 下げられる ← 今の 日本で 起きてる こと

3 番目 が 今回の 主役。

メルカリで 1,000 円 の 商品 が ある。
そこに 超 大金持ち が やってきて「ぜったい 100 円 までしか 払わん」と 言って 買いつづける。
すると どうなる？ → 相場 が 100 円 で 固定される。
大金持ち が 買うのを やめた 瞬間、本来の 1,000 円 に もどる。

これが「日銀 が 長期 金利 を キャップ してる」の イメージ。
日銀 が 「ぜったい この値段 まで しか」と 長期国債 を 買いつづけて 金利 を 上げさせない
日銀 が 長期 金利 を 下に 押さえると → 国 は 安い 利息で 借金できる → 財政 危機 が さける。
でも タダじゃ ない。なにかに しわよせ が いく。
そのしわよせ が 「円安」 という 形で 出てる ── これが Brooks の 主張。
5
STEP 5
かわせ って なに？

為替 = 円 と ドル の 交換レート。世界 が 日本 を どれくらい 信用 してるか の 通知表。

「1 ドル = 150 円」 みたいな アレ。
ふつうの 説明 だと「日米 金利差」とか「貿易の 黒字赤字」とか いろいろ 言われる。
でも Brooks は 「そんなの ほぼ 関係ない」 と 言いきってる。

大事 なのは ── 長期 金利 と くに の 信用、それだけ。
(覚えてる？ Step 3 で「通貨 に 効くのは 長期 金利」って 出てきたよね)

風船 の イメージ で 考えてみよう。

・国 の 財政 が 悪くなる = 風船 に 水 が ふえる = 圧力 が 強くなる
・ふつうは「長期 金利 が 上がる」って 穴 から 圧力 が ぬける
・でも 日銀 が その 穴 を ふさいでる (Step 4 で 見たね)
・行き場 を 失った 圧力 は「通貨 が 安くなる」って べつの 穴 から ぬける

これが 円安 の しょうたい。
圧力 は どこか から かならず 出る ── どっち の 穴 から 出るか の はなし
Brooks の キメぜりふ:
「fiscal distress は bond market か currency market の どちらか で 必ず 表出する」
= 財政の しんどさ は、国債 か 通貨 の どっちか で かならず 表に 出る。
水の量 は おなじ、出口 が ちがう だけ。
🏁
GOAL
ニュースの ことば に もどってみよう

はじめに 見た Brooks の つぶやき、もう一度 出してみるよ。

Brooks 原文 (要旨)
日本の 円 が 世界 最弱通貨 に なった。日銀 が タカ派会合 を したのに 円安 が とまらない。
これは 矛盾 ではない。日銀 は 長期国債 を 買いつづけて 長期金利 を キャップしている。
それは bond market での 財政危機 を 回避するが、圧力 を currency market に 転移させているだけだ。
日本の 高い 債務 と 財政リスクプレミアム は「弱く 下落する 円」として あらわれる。
▼
中学生 むけ 翻訳

円 が トルコ の お金 より 安くなった。日銀 が「金利 上げるかも」と 言ったのに 円が 安いまま。これは 矛盾 じゃない。

日本 は 借金 が すごく 多い 国。普通なら その不安 が「長期 金利 の 上昇」として 出るはず。
でも 日銀 が 長期 国債 を 大量に 買って 長期金利 を むりやり 低く 抑えてる。

抑えてる おかげで、政府は 安い 利息 で 借金できて、財政危機 にならずに すんでる。

でも 不安 そのものは 消えない。
国債 で 出られない なら、通貨 で 出るしかない。
だから 円 が 下がる。

円安 は ガソリン高 や 原材料高 で 個人 を 直撃 するけど、その しょうたい は 「日本の 借金 不安 が、為替 という べつの 窓 から 漏れ出してる」 という こと。
ここまで わかると、為替 ニュース の 構造 が 見える。
「日銀 が 国債 を 買うのを やめない 限り、構造 は 変わらない」── という 長い 目線 で 読める。
