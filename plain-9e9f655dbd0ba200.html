結論 (以下は旧前提: 棟ごとに別の組へ売る計算)

  • 絶景の一棟貸しが少ないのは「人」を置けないから。人のいない土地は安い (坪90円〜)。建物は小さくしても半分は下がらない。詰まるのは、毎日の清掃・湯の換水・迎えをする人の給与。
  • 1拠点 = 客室3棟 + 家守りの離れ。1棟だけでは家守りに年144万円しか払えない。3棟なら年570万円 (会社負担込み) と交代要員100万円を払って、拠点に利益が残る。
  • 成り立つ線は「1棟の年間売上780万円 (税込)」 = 1泊6.0万円×130泊。4.5万円ではどの泊数でも返済が苦しい。
  • 工場化で安くするのは、会社の利益の源泉。1棟の原価を中位1,958万円から1,650万円 (−16%) に下げて初めて、「作って売る」会社が黒字になる。量産の下げは8棟目までで14〜17%が上限の見立てで、「半額」は言わない。
  • 最初は創業者の自己資金で1棟目と離れ。12か月の関門 (年間売上・満室で断った日・口コミ・原価・水質・返済余力) を通ったら2・3棟目。投資家の出番はその後。

有望な道筋と、失敗する条件

  • 道1 1号を自分で持って証明し、開発して売り、運営を受ける: 計画Aの関門 (1泊5.0万円以上、1棟120泊と平日40泊、満室で断った日40日、口コミ、原価、水質、増設後の返済余力1.3、本人以外の運営1か月) を通してから。失敗: 関門を通らない / 1棟の原価が1,650に届かない / オーナーが6,600で買わない (全額借りれば返済後 約85) / 本人以外では質が落ちる。
  • 道2 希望の違う住み手の輪と、会員の泊数: 住み手と会員を別々に確かめる。失敗: 希望が重なる / 住み手の労働を払うと得が小さい / 会員が繁忙期に集まるか、既存の客が移るだけ / 前払いの会員の法。
  • 道3a 部品と受注製造を売る (自社の拠点は要らない): 失敗: 買う人の数が会社の固定費を払えない / 外の現場で品質を守れない / 立替が膨らむ。
  • 道3b 土地と箱で分ける (ÖÖD型): 資本は軽くない。失敗: 会社の取り分 約267 では箱の返済 約235 でほぼ消える / 分配率と契約 / 旅館業の営業者。

まだ比べていない道: 既存の宿・土地で有償の実証、他人の土地での受注製造・請負、既存物件の運営受託、地域の人で回す形。確かめる順番: ①利益と資金の定義・契約の主体 ②候補地の制約・概算見積り・客と住み手の条件 (並行) ③既存の施設で小さく有償で試す ④必要資金と撤退の条件を満たせば1号 (自己資金1,500、総額1,799〜2,888) ⑤本人以外の運営と追加の需要を確かめて増やす。独立レビュー (Codex) の指摘で、数字の定義・537→約680・返済・道3の分割を直した。
