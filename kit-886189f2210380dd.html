共通の型 (全社共通)

実額系 (「①べつに困ってない」を潰す)

  1. 最近の遠隔現場で、作業員 1 人・1 ヶ月あたりの宿+水まわりの実費は (宿代・給水運搬・くみ取り・水質検査の内訳)
  2. その費用はどの予算から。発注者に請求できているか
  3. ピーク時の現場滞在人数と、地元外から来た人の割合

失敗経験系 (深さを測る)

  1. 宿が取れない・水が足りないことによる工程・人繰りの実害。余計にかかった金額
  2. 宿・現場環境が理由の応募辞退・早期離脱の有無
  3. 船・道路が止まって水・燃料の補給が途絶えた経験

代替不満系 (「③今の方が安い」を測る)

  1. 宿・給水・トイレ・風呂を何社に分けて発注しているか。手配・調整に誰が何人日か
  2. 既存レンタル・手配サービスで「ここだけは解決されていない」点
  3. 排水の制約 (流せない・許可が面倒) と現在の処理方法

乗り換え条件系 (いくらなら払うか)

  1. 宿+水まわり (+電気) が一括・可搬で来るなら、いくら・何日短縮で乗り換えるか
  2. 現場間で同じ設備を移設して使い回せることへの追加価値

7 つの数字 (現状値を必ず取る): くみ取り回数 / 給水の輸送量 / 設置日数 / 手間の人数 / 設置面積 / 排水の許可 / 作業員 1 人あたりの総コスト

① 清水建設 (工事部隊)

検証する空き地: c ぜんぶ込みセット + a 動く設備土木×洋上の両取り
聞く相手土木の工事事務所長・現場代理人・労務担当 + エンジニアリング事業本部 洋上風力プロジェクト推進室 / SEP 運営部
避ける相手本社の技術研究所 (「清水建設は水循環の利用者じゃない」— ただし工事部隊は利用者になり得る。同じ会社の中で相手を変える)
背景 (知っていると信頼される)SEP 船 BLUE WIND = 建造費約 500 億円・国内 2 件+台湾 2 件・拠点港は室蘭・入善 ✓ / 山岳トンネル自動化で担い手不足を公式に課題化 ✓ / 2026/4 から現場監督の評価制度を役割重視に転換 / 業界標準は「現地宿舎で単身赴任の集団生活」✓
入口トーク「山岳現場の担い手不足対策を公式に打たれていますが、現場の宿舎・水まわりが採用・定着に効いている実感はありますか」
固有質問
  1. 遠隔土木現場の宿舎+水衛生の実費 (人月) と予算科目。発注者転嫁の実態
  2. 宿・給水・トイレ・食堂を何社に発注し、現場総務の調整工数は何人日か (空き地 c の生死を握る質問)
  3. BLUE WIND の拠点港を移るとき、陸上側 (宿・生活インフラ) の再調達はどうしているか
  4. 洋上風力の建設ピーク時、地元外作業員は何人・どこに泊まったか。宿不足の工程影響は
  5. 現場の排水 (浄化槽・汲み取り) で許可・手間が重かった実例。代行ならいくら払うか

② INPEX

検証する空き地: a 動く設備 + 追い風の実在確認採用投資の財布で話す
聞く相手再生可能エネルギー・新分野事業本部 技術ユニット 風力事業グループ (五島 JV 当事者) + 掘削部門の現場管理職
避ける相手経営企画・新規事業部門 (総論しか出てこない)
背景五島 = 16.8MW・6 社 JV (代表は戸田建設・INPEX は出資)・2026/1 商用開始 ✓ / 再エネ 628MW (洋上風力 333MW・地熱 119MW) ✓ / 女性掘削エンジニアの公式発信「3K だった掘削現場も女性が働きやすい環境に整備」
⚠ 五島の建設の生々しい記憶は戸田側に厚い可能性 → JV 内で誰が兵站を担ったかを聞き、必要なら戸田建設への紹介をもらう導線に
入口トーク「掘削現場の環境整備と女性技術者の増加を発信されていますよね。現場環境への投資は、いまや福利厚生でなく採用インフラだと私たちも考えていて —」
固有質問
  1. 五島の建設時・O&M 準備で、作業員の滞在・移動はどう回したか。一番困ったことは
  2. O&M は SOV/CTV (船) で足りる見込みか。陸上の宿・生活拠点への需要は残るか
  3. 洋上風力・地熱で次のサイトに移るとき、生活インフラの再調達コストは
  4. 国内の陸上掘削現場の宿舎・水まわりの実態。環境整備の予算は採用投資として通るか
  5. 海外 (Ichthys 型) では作業員キャンプの水・衛生を誰が請けたか。国内に同業態が無いことをどう見るか

入口トーク「CuboRex さんとの実証を拝見しました。機材 50kg を背負う問題を可視化されたのと同じ目線で、水・トイレ・風呂という『生活の兵站』の方はどうなっているのか伺いたく —」

  3. イオン等の協定拠点は駐車場・会議室が中心 — 給水・シャワー・トイレ側の空白はどう埋める想定か
  4. 山間部の鉄塔更新・断線対応で「機材 50kg 背負い」の水・生活版にあたる負荷は何か
  5. 前線基地パッケージ (水衛生+電源+仮眠) を平時保有 or 協定・レンタル型で持つ検討は。あるなら年いくらまで

入口トーク「台風 21 号で受けた側、能登で出した側の両方を経験されていますよね。応援部隊が持っていく『自弁の装備』は実際どこまで整っていて、何日目に破綻するのか伺いたく —」

GO/KILL 判定基準 (8/27 判定会議)

清水 (遠隔土木 = 空き地 c)
GO: 「調整に月 N 人日・実額○円」が具体的に出る + 一括化への乗り換え条件が数字で出る
KILL: 「現場総務の調整で特に困っていない」
INPEX / 清水 (洋上風力 = 空き地 a)
GO: 「港・サイトを移る再調達が 1 回数千万円級」or「宿不足の工程実害 1 件以上」
KILL: 実務責任者 2 人連続「既存ホテル+船で困っていない」
東電 / 関電送配電 (災害兵站 = 空き地 b・d)
GO: 「兵站 (宿・水・衛生) が復旧速度を落とした実例と実額」+「前線基地 or 展開キットの事前配備に調達意向 (平時保有/協定/レンタルのどれか)」
KILL: 「自弁原則+ホテル・車中泊で回っており改善優先度が低い」が 2 社連続

共通ルール: 「①困ってない」or「③今の方が安い」が 2 連続 → その候補は B に降格して次へ。
