物理整合分析(A 当事者観察ベース):
A 右側面の損傷は 後方まで長く線状に伸びてはおらず、リアドア下部に食い込むような凹み として残っている(A 本人が車両を直接確認)。
→ A の前進方向に擦り痕が長く伸びる「並走擦過」型ではなく、B が 横方向に突っ込んできた押し込み力 が支配的だった姿。
→ 両車は 並行ではなく直角に近い角度 で接触し、B 左前コーナーが A 右側面(リアドア下部)に 食い込む形で凹みを残した。
→ これは「A が動いていて B が静止していた(A の運動量だけが接触に寄与した)」というよりも、B が右折初動で出てきた運動量 + ハンドル切り込みの横方向力 が損傷を支配的に作ったことを示唆。
→ 後輪・ホイールは無傷で、損傷は リアフェンダー〜リアドア下部に局所集中。これも「並走でこすれ続けた」では説明できず、1 点に集中した直角寄り突入 と整合する。

10. 戦略・過失主張(A 希望 ⇔ 弁護士見立て 併記)

本セクションは A(依頼者)の主張(交渉の出発点) と 相談弁護士の現実的な着地見立て を併記します。交渉では強気に主張しつつ、現実ラインを把握しておくことが目的です。

10-1. 視認対称性論点(ドラレコ SSOT 基準)

📍 双方の視界対称性 + B 死角接触
A は北行き信号待ち 2 台 + 工事車両 + 青シートで t<2.5 秒まで西脇道の B を視認困難。
B も同様に北からの A を視認困難。
さらに、B は衝突瞬間まで A の両ドラレコ視野外(右側面真横の死角)に位置。
→ A は誘導員「進め」合図に従って通常走行(東側車線、一貫)。
→ B は静止していたにも関わらず、A が交差点通過中に右折に転じようとした(車体はほぼ静止のまま A 右側面に接触)。
→ B の右折開始判断ミスが主因(対称的視認不能 + B の右折初動〔車体ほぼ静止〕+ A 死角接触)。
