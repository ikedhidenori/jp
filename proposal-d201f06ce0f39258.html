Plan A — 完全独立 L 字配置
JPY 50,000,000 / 5,000 万円

水回り棟 + リビング棟、
中庭で完結する 独立宿泊空間。

IZH ユーティリティ棟

西壁沿い 6.12m × 2.37m。水循環システム / シャワー / バイオトイレ / PV 3kW + 蓄電 24kWh。

IZH リビング棟

北壁沿い 6.12m × 2.37m。寝室 / リビング / ダイニング / PV 1.5kW + 蓄電 15kWh。

L 字デッキ

2 棟を結ぶ 30㎡。ソファ / ローテーブル / 焚き火台。北西角を起点に中庭中央へ伸びる構成。

既存建物への接続なし。ライフライン独立。建築確認不要 (IZH = 車両扱い)。

Plan B — 灰スチール基幹 + 浴槽
JPY 40,000,000 / 4,000 万円

水処理基幹を分離し、
居住棟に 檜の浴槽 を据える。

INNFRA Base (灰スチール)

西壁沿い 3.6m × 2.4m。水循環 / 雨水収集。建材は灰スチール仕上げ、中庭の石壁と調和。

IZH リビング棟

北壁沿い 6.12m × 2.37m。寝室 / シャワー / バイオトイレ / キッチン。生活機能を 1 棟に集約。

L 字デッキ + 木製浴槽

檜製浴槽 1.5m × 1m × 0.7m。デッキ南端に半埋設、空を眺める入浴体験。

水処理棟を小型化することでコスト低減。基幹機能は維持。

Plan C — 既存ギャラリー連携
JPY 30,000,000 / 3,000 万円

寝室は既存ギャラリーへ。
中庭は 水回りとデッキ に。

IZH ユーティリティ棟

北壁の西寄りに配置。水回りを集約。設備パッケージは Plan A の水回り棟に準じる。

寝室 — 既存ギャラリー内部

既存建物内の一室を寝室として活用。フォトアートミュージアムの内部空間を生活に組み込む。

L / T 字デッキ

面積 32㎡。IZH 棟から東側ガラスドアまで連続。中庭と既存建物を物理的につなぐ動線。

既存建物の改装が並行発生。完成 1–2 ヶ月遅延を見込む。

Plan C′ — 浄化槽地中化
JPY 30,000,000 / 3,000 万円

浄化槽を地中へ。
清里の冬を見据えた 凍結対策。

構成 — Plan C と同一

IZH ユーティリティ棟 / 既存ギャラリー寝室 / L・T 字デッキ 32㎡。建物配置は変えない。

差分 — 浄化槽地中設置

デッキ南端の地中に埋設。地上は芝生盛り土 1.5m × 1.5m × 0.3m で覆い、中庭の連続性を保つ。

採用理由

清里冬季 (氷点下 -10℃ 想定) での凍結リスク回避。地表設備を減らし、中庭の見え方も整理。

地中工事 1 週間の追加。本体価格は Plan C と同等。
