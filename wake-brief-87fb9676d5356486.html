Backup Plans

トレーラー搬入 NG 時の建築切替

西壁 pilotis ~3m 通過で詰まった場合、各案を建築扱いに切替可能。基礎工事 + 確認申請が追加。

A 案 → 建築版

Base Lite を建築扱いに変更 (+230 万)

RC ベタ基礎 150 + 建築確認 + 監理 80。総額 約 1,990 万 (税別)。失うもの: 移設可能性 + 非課税。

B 案 → 建築版

MOKUJIKU → MUJI 小屋 (12 ㎡ 木の小屋) (+280 万)

本体 +500 (300→800) + RC ベタ基礎 200 + 確認申請 80、ただし搬入費 −60。総額 約 2,590 万 (税別)。失うもの: 移設可能性 + 非課税。意匠は深澤直人ブランド。

C 案 → 建築版

Base を建築扱い + IZH → MUJI 小屋 (−240 万)

IZH 撤去 (−1,500) + MUJI 小屋追加 (+800) + RC ベタ基礎 × 2 (400) + 確認申請 × 2 (160)。総額 約 3,820 万 (税別)。
失うもの: PV 1.5kW + 蓄電池 15kWh → 災害対応 ○ → △ に降格。意匠は深澤直人。
