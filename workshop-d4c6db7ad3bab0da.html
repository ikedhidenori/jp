2030-2040 AI以降のワクワク未来を描く SFプロトタイピング・ワークショップ設計

作成日: 2026-07-09
実施予定: 2026-07-10 13:00 JST
扱い: 限定共有用 参照: 仮説検証マップ / 描ける世界ボード

1. 修正後の前提

明日の集中討議は、今日の議論をいったん忘れて始める。

今日の議論は、現在の具体的な論点にかなり立脚していた。特に現時点の実務課題に寄ったため、明日は同じ文脈から始めない。

明日の主眼は、ゼロベースで「2030-2040年のAI以降に、どんな未来なら本当にワクワクするか」を描くこと。課題解決から入らず、ほしい暮らし、ほしい仕事、ほしいまち、ほしい遊び、ほしい関係性、ほしい会社、ほしい社会を先に想像する。

SFプロトタイピングは、未来の困りごとを探すためだけの手法ではない。まだ存在しない日常、道具、習慣、サービス、儀式、風景を仮につくってみることで、いまの自分たちの想像力を広げるために使う。

追加のブレスト素材は、「そのまま議題に戻す」のではなく、未来を広げるための火種として扱う。特に使うのは、Why / Who / How のうち Why の層、つまり「どんな世界を作りたいか」「どんな場所や時間なら人が行きたくなるか」「使った人が帰ってから何と言うか」だけに絞る。

仮説検証マップから混ぜるのは、検証フェーズや優先順位ではなく「描ける世界ボード」の言葉。明日はこれを評価軸ではなく、未来の絵を描くための詩的な材料として使う。

2. 明日のゴール

完成した事業戦略を作る場ではない。まずは未来のテンションを上げる。

明日の成果物は、次の4つ。

  1. 2030-2040年の「ワクワクする未来シーン」 5-8個
  2. その未来に出てくる、まだない道具・サービス・場所・習慣のラフ案
  3. チームが「これは見たい」「これは作ってみたい」と思える未来コンセプト 3つ
  4. その未来に近づくための小さな実験候補

注意点: - 最初から市場性、収益性、既存技術、導入先、社会課題に落とさない。 - 「誰が困っているか」ではなく、「誰が嬉しくなるか」「どんな一日が楽しくなるか」から始める。 - 現実に戻すのは最後でよい。

3. 混ぜる材料: 描ける世界ボード

仮説検証マップから持ち込む言葉:

  • サバイバル & ウェルビーイング
  • パンとバラ
  • インフラ起点のライフスタイルクリエイター
  • VLDK / TOUCH
  • ネオ・オフグリッド
  • 生存圏の拡大
  • 共同体自治・社会的共通資本
  • ブレイクスルーリビング
  • 地球のすべての夜に灯りと潤いを
  • くらしを自在にする

読み替え:

  • サバイバル & ウェルビーイング: 生き延びるだけでなく、よく生きる。
  • パンとバラ: 必要なものと、美しいもの。生活の最低限ではなく、生活の喜びまで扱う。
  • インフラ起点のライフスタイルクリエイター: 裏側のインフラから、新しい暮らし方・遊び方・働き方を作る人たち。
  • VLDK / TOUCH: 箱ではなくプロトコル。生活者視点、コントローラブル、アフォーダブルを未来の日常に翻訳する。
  • ネオ・オフグリッド: 我慢や孤立ではなく、場所を自由に選べる感覚。
  • 生存圏の拡大: 人が気持ちよく暮らせる場所の選択肢が増えること。
  • 共同体自治・社会的共通資本: まちや仲間が、自分たちの暮らしを自分たちで編集すること。
  • ブレイクスルーリビング: 生活そのものが、新しい産業・文化・体験になること。

迷ったらこの2軸に置く:

  • 横軸: サバイバル（死なない） ←→ ウェルビーイング（豊かさ・自由）
  • 縦軸: 個人・暮らし ←→ 社会・コミュニティ

明日は意図的に右側、つまり「豊かさ・自由」側を厚くする。左側のサバイバルは大事だが、昨日十分やったので起点にしない。

4. ファシリテーション原則

  • 今日の話題は、冒頭でいったん箱にしまう。
  • 最初の90分は「無理そう」「それは既にある」「誰が払うの？」を禁止する。
  • AI技術の正確な予測より、生活者の感情と風景を優先する。
  • 未来を暗いディストピアだけにしない。まず楽しい未来を描く。
  • 「プロダクト」より「日常のワンシーン」を先に作る。
  • 「正解」ではなく「見てみたい未来」を出す。
  • 過去素材を使う時は、固有の課題名ではなく、未来の場所、生活感、習慣、口ぐせに変換してから出す。
  • 最後だけ、今の事業仮説や実験へ軽く接続する。
  • Must / Can より先に Will を出す。何を目指したいかが先。
  • 「課題解決 vs 豊かさ」の往復が始まったら、今日は豊かさ側に一度倒す。

5. 冒頭のリセット宣言

そのまま読める台本:

今日は、昨日の議論をいったん忘れます。
昨日は現実の論点や現実の論点にかなり寄りました。もちろん大事ですが、今日はそこから離れて、2030年から2040年にAIが社会に深く入ったあと、どんな暮らしや仕事やまちなら本当にワクワクするのかを考えます。
今日は課題解決から始めません。まず「こんな未来を見たい」「この日常は楽しそう」「このサービスがあったら使いたい」という感覚から始めます。
途中で現実性を詰めたくなっても、前半は我慢します。最後にだけ、今の自分たちが何を試せるかに戻します。

6. 推奨アジェンダ

13:00-13:10 オープニング: 昨日を箱にしまう

目的: - 昨日の議論に引っ張られないよう、場のモードを切り替える。

やること: - ホワイトボードに「今日はゼロベース」「課題起点禁止」「ワクワク優先」と書く。 - もう一つ、ホワイトボードに「今日は Will から」と書く。 - 昨日の具体論は「あとで戻す箱」に入れる、と宣言する。 - 参加者に「今日は実現性より、見てみたい未来を優先する」と合意してもらう。

13:10-13:30 ウォームアップ: 2035年の最高の朝

問い: - 2035年、AIが生活に自然に溶け込んだ世界で、最高に気持ちいい朝はどんな朝か。 - 起きてから最初の30分に、何が起きていると嬉しいか。 - 誰と、何と、どんなふうに関わっているか。

書くもの: - 1人3枚。 - 書式: 「2035年の朝、私は ____ している。なぜなら ____ だから気持ちいい。」

狙い: - 未来を課題からではなく、身体感覚と喜びから始める。

13:30-13:45 描ける世界カードを混ぜる

仮説検証マップの「描ける世界ボード」から、言葉だけを場に出す。

やること: - 各自、気になる言葉を2つ選ぶ。 - その言葉を「2035年の楽しい日常」に言い換える。

例: - パンとバラ → 必要なものだけでなく、美しい時間まで整う暮らし - ネオ・オフグリッド → どこでも孤立せず、自分のペースで暮らせる自由 - 共同体自治 → まちが自分たちの手で少しずつ編集される感覚

13:45-14:10 AI以降のワクワク変化カード

参加者が、AIによって面白く変わりそうな領域を出す。

領域例: - 暮らし: 家、食、移動、健康、家族、趣味 - 仕事: チーム、意思決定、商売、職人性、学習、創作 - まち: 交通、店、公共空間、コミュニティ、観光 - 関係性: 友人、家族、先生、顧客、地域、AIとの相棒感 - 時間: 余白、集中、遊び、睡眠、旅、季節 - 自然: 海、山、島、森、都市との距離感 - お金: 所有、共有、信用、報酬、贈与

追加で混ぜる火種: - 疎空間でも、生活と冒険が両立する。 - 自然、島、山、道の駅、廃線、高架下が、AIによって「行きたい場所」に変わる。 - 水、電気、トイレ、洗濯、宿泊のような生活機能が、場所の制約を外す。 - 小さなチームとAI社員が、少人数でも大きな探索を進める。 - 滞在、研修、自然、対話が混ざり、「問いを取り戻す旅」になる。 - 使った人が帰ってから、誰かに言いたくなる一文が生まれる。

問い: - AIによって、何がもっと自由になるか。 - AIによって、どんな小さな贅沢が増えるか。 - AIによって、どんな新しい遊び方・働き方・暮らし方が生まれるか。 - 2030年代に「それ、昔は人間が全部やってたの？」と言われそうなことは何か。 - 2030年代に「昔はそこに行くのを諦めていたの？」と言われそうな場所はどこか。 - 2030年代に、小さな会社や個人チームが大きく動けるとしたら、何が変わるか。

出すもの: - 1人5-8枚の変化カード。 - まだ事業名にしない。未来の変化として書く。

14:10-14:45 未来世界を4つ作る

2軸で未来を分け、4つの世界を作る。

軸: - 横軸: サバイバル ←→ ウェルビーイング・豊かさ・自由 - 縦軸: 個人・暮らし ←→ 社会・コミュニティ

補助観点: - AI: 裏方にいる世界か、人格/相棒として前に出る世界か。 - 場所: 都市の中で濃くなる未来か、自然・島・山・疎空間へ広がる未来か。 - 生活機能: 便利さが見える未来か、裏側に溶けて人は体験だけを楽しむ未来か。 - チーム: 個人とAIで完結する未来か、人間同士が新しい形で合流する未来か。

4つの世界例: 1. パンとバラの生活圏
必要なものが整うだけでなく、美しさや遊びまで自然に届く。 2. AI相棒と暮らす世界
人はAIと一緒に旅し、学び、働き、創作する。 3. ネオ・オフグリッドな自由生活
場所に縛られず、自分のペースで暮らしと仕事を組み替える。 4. 共同体が編集するまち
公共空間、店、移動、イベント、学びが、住民とAIでゆるく編まれる。

やること: - 4つの世界に名前をつける。 - それぞれの世界で「楽しそうな日常」を3つ書く。

14:45-15:20 2035年の一日を物語にする

各チームで1つの世界を選び、主人公の一日を書く。

主人公候補: - 2035年の20代クリエイター - 2035年の地方で暮らす家族 - 2035年の小さな会社の経営者 - 2035年の旅しながら働く人 - 2035年の学び直しをしている大人 - 2035年の高齢者 - 2035年のまちの店主 - 2035年の子ども

テンプレート: - 主人公: - 場所: - 朝: - 昼: - 夜: - AIが自然にやっていること: - 人間があえて自分でやっていること: - その世界で生まれた新しい楽しみ: - その世界で流行っている言葉: - その世界にある、まだ名前のないサービス: - その世界は「パン」と「バラ」の何を満たしているか:

15:20-15:30 休憩

15:30-16:10 SFプロトタイプを作る

未来の一日から、ひとつの「存在しないけど欲しいもの」を選び、SFプロトタイプにする。

形式はどれか1つ: - 2035年の広告 - 2035年のサービスLP - 2035年のアプリ画面の説明 - 2035年のユーザー日記 - 2035年のニュース記事 - 2035年の招待状 - 2035年の店頭POP - 2035年の学校の時間割 - 2035年の旅のパンフレット - 2035年の取扱説明書

必須要素: - 名前 - キャッチコピー - 誰が使うか - どんな気持ちになるか - どんな一日が変わるか - AIは何をするか - 人間は何を楽しむか - 友達にどう説明するか - なぜ2030年代らしいのか - どの「描ける世界カード」から生まれたか

16:10-16:40 未来の魅力を磨く

問い: - これを見た人は、なぜ欲しくなるか。 - どの瞬間がいちばんワクワクするか。 - どんな写真、映像、体験にすると伝わるか。 - これがある世界では、人の時間の使い方はどう変わるか。 - この未来の一番美しいシーンはどこか。 - 体験した人が帰ってから、友人にどんな一文で話すか。

出すもの: - 未来コンセプトごとに「最高の1シーン」を1枚書く。

16:40-17:10 未来コンセプトの展示会

やること: - 各チーム3分で発表。 - 聞く側は質問ではなく、まず「いいなと思ったところ」を付箋で貼る。 - 次に「もっと未来っぽくするなら？」を1つだけ出す。

投票: - 見てみたい未来票 - 使ってみたい票 - 自分たちらしい票

17:10-17:35 Will / Can / Must を軽く見る

ここで初めて、仮説検証マップ側のフレームを使う。ただし重くしない。

問い: - Will: これは自分たちが本当に見たい未来か。 - Can: 自分たちが関われる余地はどこにあるか。 - Must: なぜ2030年代に必要になるのか。

注意: - Mustから始めない。 - Canで小さくしすぎない。 - Willが弱いものは、いくら現実的でも明日の本命にしない。

17:35-17:50 現実へ軽く橋をかける

ここで初めて、今の事業や探索に軽く戻す。

問い: - この未来のどこに、自分たちが関われる余地があるか。 - いま既に小さく始まっている兆しは何か。 - 2週間で試すなら、何を見せれば反応が取れるか。 - 誰にこの未来を見せたら、いちばん面白い反応が返ってくるか。

注意: - ここでも、完全な事業計画にしない。 - 「検証」より「次に会話したい相手」「次に見せたい絵」を決める。

17:50-18:05 3つの未来を選ぶ

選ぶもの: - いちばんワクワクする未来 - いちばん自分たちらしい未来 - いちばん人に見せて反応を見たい未来

各未来について決める: - タイトル: - 一文説明: - 最高の1シーン: - 次に作るラフ: - 最初に見せる相手:

18:05-18:10 クロージング

最後に一人ずつ答える。

  • 昨日までの自分たちの発想から、何が一段外れたか。

8. 明日の問いリスト

暮らし

  • AIが家に溶け込むと、家はどんな場所になるか。
  • 人が家事から解放されたら、余った時間で何をしたくなるか。
  • 2035年に「いい暮らし」と呼ばれるものは、いまと何が違うか。

仕事

  • AIが資料作成や調整をほぼ担うと、人間の仕事で楽しく残る部分は何か。
  • 小さな会社が大企業並みに動けると、どんな商売が増えるか。
  • 2035年のチームは、人間とAIがどう混ざっているか。
  • 2035年の「AI社員」は、会社の何を広げ、何を人間に残すか。

まち・場所

  • まち全体がAIで編集されると、どんな散歩や買い物や遊びが生まれるか。
  • 地方や島や山での暮らしは、AIによってどう魅力的になるか。
  • 2035年に「行きたい場所」は、観光地ではなく何になるか。
  • 疎空間でも生活と冒険が両立すると、どんな場所が急に面白くなるか。
  • 水、電気、トイレ、洗濯、宿泊が場所に縛られなくなると、人はどこで何を始めるか。
  • まちの空き地、道の駅、廃線、高架下、港、公園は、2035年にどんな日常の舞台になるか。

学び・創作

  • AIが先生にも相棒にもなると、学びはどんな遊びに変わるか。
  • 誰もが創作できる時代に、人は何を見せ合うか。
  • 2035年の子どもは、何を当たり前に作っているか。

関係性

  • AIが人間関係を補助すると、友人、家族、地域との距離はどう変わるか。
  • AI相棒がいることで、人はもっと一人でいられるのか、もっと誰かとつながるのか。
  • 2035年に増える新しい儀式や集まりは何か。

時間・余白

  • AIで効率化された世界で、人は何にゆっくり時間を使うか。
  • 「待つ」「迷う」「寄り道する」は、2035年に価値になるか。
  • 未来の贅沢は、便利さではなく何になるか。
  • 滞在や旅が「問いを取り戻す時間」になるなら、どんな一日になるか。

描ける世界ボード由来

  • パンとバラ が2035年の日常になると、どんな朝・店・旅・仕事が生まれるか。
  • インフラ起点のライフスタイルクリエイター は、2035年にはどんな職業や役割になっているか。
