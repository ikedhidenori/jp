INNFRA 未来仮説×事業仮説 最終統合 v1.0

採用した構え (素子判断、2026-07-15 昼): 二階建て — 価値原理 = 尊厳のミニマム (機械浴テスト) × 経済エンジン = C 規格背骨 (B 直営・A 参照実装を従属)。理由: 尊厳は全世界線・全シーンで生き残った唯一の価値軸であり、C は全世界線で売れる唯一の経済層。両者を分けることで「測れるものに仮説が乗っ取られる」ことと「ワクワクだけの空疎化」の両方を防ぐ。

1. 一文で表した未来仮説 【確信度: 中 / 本人回答+検証済+推論】

単身化と生存コスト危機が進む 2040 年の日本で、住宅は「箱の所有」から「尊厳のミニマム (寝る・立てる・暖かい・洗える・水がある) を保証する器と、それを支える網への接続権」へ解体・再結合される。その成立可能性は、既設インフラなしで水・衛生・エネルギーを賄う規格が握る — INNFRA はその規格を書く会社になる。

2. 10〜20 年後に変化する社会的前提 【確信度: 高 (人口・水道) 〜 中 (コスト乖離)】

  • 単独世帯 43.5% = 2,442 万で最大類型 (2040、ピーク 2036)。高齢単身 1,041 万 = 1.4 倍 【検証済⚠社人研 2024】
  • 高齢者増の約 66% (+211 万人) が東京圏に着弾 — 高齢化は都市の問題になる 【照合済⚠第一生命経研】
  • 水道: 2046 年までに 96% の事業体が値上げ必要・平均 +48% (推計)。2024 年に 82 事業者が実際に値上げ (最大 4 割・800 万人)、管路更新 130 年ペース = 進行中の実測 【検証済⚠】
  • 空き家は広義 1,861 万戸・25.3% (2043 推計) — ただし「家余り」は「住める器余り」ではない (危険空き家倍増、単独世帯は戸建を選ばない) 【照合済⚠NRI】
  • 若年の在宅化は 34 年一貫 (20 代の休日移動ゼロ 52.4%)、移動の主役は 70 代へ逆転 【検証済✅国交省】
  • 労働供給 1,100 万人不足 → 「施設に人を集めてケア」モデルの崩れ 【民間推計】
  • 生存コスト (家賃+光熱+ケア) と実質手取りの乖離が中間層下半分に到達 【推論 — 先行指標: 実質家賃/賃金比】

3. 解体・再構成される住宅機能 【確信度: 中 / 本人回答 (N=1)+推論。一般化可能性は未確認】

  • 三層解体: 外部化容易 (洗濯・映像・冷蔵) / こだわり携行 (コーヒー・音) / 還元不能の核 = ①尊厳ある寝心地 ②立てる高さ ③温熱
  • 水は単身生存では外部化可能だが、N≥2・女性・親密さ・尊厳が入ると核に戻る (水の必然性は生存でなく関係から)
  • 最小単位は世帯 → 個人 (一人一部屋、VLDK V=3.3 畳下限)
  • 再結合の型: 核は所有 (器 100 万)、残りは網から月額で接続 — 3,000 万の借金の解体

4. 新しく生まれる欲望・不安・ニーズ 【確信度: 中 / 本人回答+推論。定量は未確認 → 検証 14-①】

  • 「家賃 (住コスト) のために生きる」倒錯からの解放 — 蓋をされた全員の怒り (仮説)
  • 呼吸できるスペースの確保 (都市の金融化の主観的裏面)
  • プア標準世界 (安い擬似体験が多数派) での「尊厳の一点」保持 — 機械浴の拒否、檜の風呂椅子
  • 家族という受け皿を持たない初の高齢世代の「尊厳ある自立」

5. 会社が実現したい世界と担う役割 【確信度: 中 / 本人回答+統合】

描ける世界 (N-10 の 10 個目ではなく、判定器つきの候補): 「誰もが — 所得と場所と年齢と世帯形態に関わらず — 尊厳のミニマムを月数万円で選べる国」。 役割: その最低線を規格として供給する = ビジョン「地球のすべての夜に灯りと潤いを」の実装値。サバイバル (死なない=C) とウェルビーイング (尊厳=価値原理) を一語で貫き、R1 の 5 回目の堂々巡りを終わらせる。

6. 意思決定基準としてのビジョン 【確信度: 中 / 本人回答+推論】

  • 機械浴テスト: これは檜風呂か、機械浴か (尊厳なき最安生存の量産はやらない)
  • 場所 3 条件 (正統性/特権性 × インフラ不在 × 技術突破): どこでやるかのゲート (運用されていなかった R3 を規格に昇格)
  • 規格貢献テスト: この案件は C 規格のデータ・実績・標準化に貢献するか (供給側都合の A-B 帯案件を断る理由になる)

7. 水・エネルギー+αの不可避な課題 【確信度: 高 (水道) / 中 (他)】

  • 集中型インフラの限界コストが構造的に上がり続ける (人口減×更新負債) — 実測で進行中
  • 器を置ける場所が既設網に縛られる — B 先行者 (HafH/LAC) の死因は光熱費・原価 = C の不在 【検証済⚠】
  • 単身高齢の在宅限界: ケアが器に来るには水・衛生・温熱の自律が前提
  • 酷暑の常態化 × 電気 — 温熱の核が電力問題に還元される

8. 顧客、利用者、支払者 【確信度: 中 / 既存実績+推論。生活者 WTP は未検証】

  • 24 ヶ月 (シリーズ A 期): B2B/B2G — 自衛隊・防災 (岩崎ファネル D 帯 = 収益スパイン)・ゆたかけあ型ケア事業者・空き家リノベ事業者・器メーカー。全て「C 規格の初期顧客」と再解釈できる
  • 中期 (2030 年代): 生活者 — 移動する高齢者 (70 代>20 代の実測に沿う)・降りる中間層・二人暮らしの水核化層。月 8 万 = 家賃 6.5 万+光熱水 1.5〜2 万の統合価格 (置換であって上乗せではない)
  • 交差する支払者: 行政 (災害・福祉・関係人口)。トークン/地域経済への現金注入源 = 都市から来る月額のレベニューシェア

9. サービスと事業モデル 【確信度: 中 / 推論+本人回答】

二階建て構造: - 価値原理 (何者か): 尊厳のミニマム — 全プロダクトを機械浴テストで判定 - 経済エンジン (何で稼ぐか): C = 水・衛生・エネの自律規格 (機器販売 + 施工規格 + 遠隔監視 RaaS + 将来ライセンス) - B = 直営 1 号網 (エクスト→停泊・滞在点): 規格を書くためのデータ源・ショールーム (テスラ充電網型)。収益 KPI から解放し規格 KPI へ - A = 参照実装 (死なないシェルター = 規格内蔵の器、9 月投資判断と接続)

10. 市場規模のレンジ、算定根拠、市場形成経路 【確信度: 分母=高 (実測/照合済) / 浸透率=低 (未検証)】

  • C: 上下水料金市場 4.2 兆円/年 (実測 2023) + 更新投資 1.5 兆円/年。+48% 値上げ = 年 1.3 兆円級の追加負担が生活者に着弾 — この負担増分が分散型代替の理論上限。経済合理の閾値特定が次の検証 (14-②)
  • A+B: 家賃市場 12 兆円/年の置換。単独世帯 2,442 万 × 月 8 万: 浸透 1% = 年 2,300 億 / 5% = 1.2 兆 / 10% = 2.3 兆。現 RV 市場 0.11 兆円 = 3 桁下からのスタートと正直に言う
  • 経路: B2G/B2B 実需 (D 帯) → 空き家×規格キット (競合を販路化) → 生活者の器+網。時間窓: 単独世帯ピーク 2036 — 規格の席は 2030 年代前半に埋まる

11. 巨大化への戦略と right-to-win 【確信度: 低〜中 / 推論。技術優位の客観検証が未】

  • 戦略 = テスラ型: 直営網 (B) で規格を書き、参照実装 (A) で証明し、規格 (C) を開いて業界標準へ
  • right-to-win の候補: ①水循環の実装実績 (富士川・彩湖・OIST・中城) ②場所の目利き (4K・3 条件 = 中城で証明) ③先行的中の直感 5 件 (SANU・核シェルター・OGR・VLDK・洗濯外部化) ④尊厳原理 = コモディティ化の防壁
  • 正直な弱点: 技術優位の客観検証は未 (wota 等競合との比較)。「規格を書く」ポジションの獲得可能性そのものが最大の未検証仮説

12. 最初の wedge 【確信度: 中 / 本人回答】

  • エクスト = 規格を書くための直営予行練習装置 (収益事業の期待から解放し、B 実験室として KPI 再定義)。菊永「POC の域を出ない」への回答 = POC であることこそ役割
  • 並走 wedge: ゆたかけあ型ケア × 檜風呂 = 尊厳 WTP の最初の実地検証 (D 帯実顧客)
  • 屋久島は場所 3 条件不成立で wedge から外す (本人判定 2026-07-15)

13. 最大のリスク、矛盾、反証条件 【確信度: 高 (列挙の網羅性) — 宿題 §4 を正式採択】

反証条件・先行指標 6 分岐 (宿題 §4 の表をそのまま資料に添付し、以後この表で答え合わせ): 1. 移動需要の反転 → B の形 (移動網 vs 定置網) を決める / 2. 都市急崩壊はブースター分岐 (前提にしない) / 3. 網の経済性 — C 規格を持つ網だけが黒字化するか / 4. 技術コスト崖 — 日本の太陽光は世界の 1.7 倍で崖が遅れるリスク / 5. 制度 — コンパクトシティ 971 市町村は現役強化中 = 分散居住への制度逆風は既に強い / 6. 時間窓 — 単独世帯ピーク 2036 追加リスク: ①尊厳 WTP が実在しない (機械浴で十分な世界) — 14-① で最初に検証 ②水技術のコモディティ化 (11 の弱点) ③社内構造リスク — R1-R5 の堂々巡りが資料でも再燃する (対策 = 反証条件表の合意で「答え合わせの日付」を決める) 内在する矛盾: 社名も特許も原体験もオフグリッドなのに「オフグリッドは手段」と言い切る緊張 (R4)。二階建てはこれを緩和するが消しはしない。

14. 2 週間で実施する検証 【確信度: 高 (実施可能性) / 効果は未確認】

  2. 分散型の経済合理閾値の一次試算: 自社実データ (富士川・彩湖の実コスト) vs 集中型料金 +48% 世界 — C の「売れる価格」の初期値
  3. B 需要の一次観測: RV パーク運営者 3〜5 件ヒアリング (稼働率統計が業界ゼロ = 誰も測っていない空白を最初に埋める)
  4. 7/16 で反証条件表を合意 — 以後の議論をこの表への答え合わせに固定 (堂々巡り R1-R5 の構造的封じ)

15. 社内が「これならあるかもしれない」と議論を続けられる説明 【確信度: 中】

「これは新事業の思いつきではない。水道値上げ 82 事業者・単独世帯 43.5%・HafH の死因 (光熱費) — 外部で既に始まっている変化が、うちの既存 3 資産 (死なないシェルター・エクスト・水循環技術) に初めて役割分担を与えた、という話。エクストは収益で測るから引き裂かれる — あれは規格を書くための予行練習装置で、稼ぐのは自衛隊と防災。そして中城の夜に私たちが身体で確認したもの — あれが『尊厳のミニマム』であり、機械浴の反対側であり、この会社が量産すべき体験の原器だ」

  • 川島対応: 外部既成事実の束で提示 (SANU 型の受容形式)。岩崎対応: ファネル D 帯 (自衛隊・ゆたかけあ) が C の初期顧客である整合 + 宇沢/社会的共通資本 (N-28) は「尊厳のミニマムの公共財化」として腹落ちの席がある

  1. L1 の言葉として「尊厳のミニマム」を仮決めするか (10 個目のフレーズではなく、機械浴テストという判定器つき — 決め切るプロセスは「反証表への答え合わせ」で担保)

  4. 反証条件表の採択: 6 分岐+先行指標を資料に添付し、次回以降「答え合わせの日付」を決める
  5. 2 週間検証 4 点の owner と期限 (7/24 株主定例の前に 1 点でも初期値を持つ)
